# リフォーム顧客フォルダ

リフォームのお客様を、反響（来店・問い合わせ）から成約・失注まで記録するページです。次のことを集計できます。

- 集客数、成約数、失注数
- 成約率（成約÷（成約＋失注）、成約÷集客数）
- 成約理由・失注理由のランキング
- 集客経路別の成約率、工事内容別の成約率
- 期（10月〜9月。40期 = 2026年10月〜2027年9月）ごとの集計と、単月の集計

## 使い方

本番のページは claude.ai の Artifact として動いています。お客様のデータは claude.ai 側に保存されます。

このリポジトリにあるのは、ページの設計図（`index.html`）だけです。お客様のデータは入っていません。

`index.html` を claude.ai の外（ブラウザで直接開く、GitHub Pages など）で開くと、画面は表示されます。ただし、保存先に接続できないため、お客様の登録や保存はできません。
